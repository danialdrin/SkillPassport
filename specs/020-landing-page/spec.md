# Feature Specification: AI-Powered Student Skill Intelligence Landing Page

## Objective
Design and build a landing page for the **AI-Powered Student Skill Intelligence Platform** at root route `/` following the application's exact theme system (`--color-paper`, `--color-surface`, `--color-ink`, `--color-mastered`, `--font-serif`, `--font-mono`).

## Core Sections & Features
1. **Header / Navigation Bar**:
   - Product Mark + `Skill Intelligence`
   - Links: How It Works, Skill Passport, Intelligence, For Students, For Institutions
   - CTAs: Sign In (`/login`), Get Started (`/register`) / Go to Workspace (`/home`)
2. **Hero Section**:
   - Eyebrow: `YOUR SKILLS. ONE INTELLIGENT PASSPORT.`
   - Main headline: `Know what you know. Prove what you can do.`
   - CTAs: `Build My Skill Passport`, `See How It Works`
3. **Hero Visual — Digital Skill Passport**:
   - Liquid water-wave fill animated skill cards (React 76%, Python 84%, Problem Solving 88%, Communication 81%).
   - Expandable sub-skill breakdown (Components 90%, Props 87%, State 72%, Hooks 64%, Context 51%, Routing 81%).
4. **Learning Sources Convergence Strip**:
   - YouTube, NPTEL, PDFs, Courses, GitHub, Projects, ChatGPT, Self Learning -> Digital Skill Passport.
5. **Problem & Solution Pipeline**:
   - Disconnected learning experiences -> Learn -> Understand -> Assess -> Verify -> Track -> Grow.
6. **Resource Intelligence (Medium Analysis vs Strong Analysis)**:
   - Search filtering (difficulty, quality, relevance) vs Deep extraction (concepts, definitions, timestamps, hotspots).
7. **Interactive Knowledge Graph Preview**:
   - Connected concept nodes highlighting sub-skill strengths & focus recommendations.
8. **Interactive AI Tutor & Contextual Assistant Preview**:
   - Chat thread showing material awareness and gap targeting.
9. **Assessment, Verification & Programming Intelligence**:
   - Evidence -> AI Assessment -> Verified Competency flow; 4 hint states & 6 evaluation dimensions for code.
10. **Digital Skill Passport Showcase & Skill Gap Intelligence**:
    - Living dashboard preview, cross-skill vs within-skill gap discovery, target role progression.
11. **Career Readiness & External Learning Ingestion**:
    - Skills -> Roles match, Role -> Skill gap analysis, external learning verification.
12. **For Students, For Institutions & Footer**:
    - 4 Student benefits, read-only institutional capability access, product/institution footer links.
