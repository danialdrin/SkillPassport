# Data Model Specification — MongoDB Collections & Schemas

This document defines the database schemas, entity relationships, and validation constraints for the platform.

---

## 1. Entity-Relationship Conceptual Diagram

```
User (1) ───────────< Resource (N)
                       │
                       └─── (1) ───> Analysis (1)
                                      │
                                      ├───< Concept / SkillNode (N) ───< KGEdge (N)
                                      │
                                      └───< Assessment (N) ───< Attempt (N) ───> CompetencyEvent (N)
                                                                                     │
                                                                                     v
                                                                             StudentKGState (1 per User-Node)
```

---

## 2. Collections & Field Specifications

### 2.1 `users`
Stores student accounts and authentication credentials.
```json
{
  "_id": "ObjectId",
  "name": "string (min 2 chars)",
  "email": "string (unique, lowercase)",
  "password_hash": "string (bcrypt hash)",
  "created_at": "datetime (UTC)"
}
```
**Indexes**:
- `{ "email": 1 }` (unique)

---

### 2.2 `resources`
Stores metadata for ingested resources (YouTube links or uploaded PDFs) and Medium Analysis results.
```json
{
  "_id": "ObjectId",
  "user_id": "ObjectId (ref: users)",
  "source_type": "string ('youtube' | 'pdf')",
  "url_or_file": "string",
  "title": "string",
  "status": "string ('pending' | 'medium_analyzed' | 'selected' | 'strong_analyzed')",
  "medium_analysis": {
    "relevance": "float (0.0 - 1.0)",
    "topic_coverage": "float (0.0 - 1.0)",
    "depth": "float (0.0 - 1.0)",
    "examples": "float (0.0 - 1.0)",
    "clarity": "float (0.0 - 1.0)",
    "structure": "float (0.0 - 1.0)",
    "redundancy": "float (0.0 - 1.0)",
    "overall": "float (0.0 - 100.0)",
    "transcript_available": "boolean"
  },
  "created_at": "datetime (UTC)"
}
```
**Indexes**:
- `{ "user_id": 1, "created_at": -1 }`

---

### 2.3 `analyses`
Stores deep semantic extraction output generated by OmniRoute LLM during Strong Analysis.
```json
{
  "_id": "ObjectId",
  "resource_id": "ObjectId (ref: resources)",
  "transcript_or_text": "string",
  "version": "integer (default 1)",
  "topics": [
    {
      "topic": "string",
      "subtopics": ["string"],
      "difficulty": "string ('beginner' | 'intermediate' | 'advanced')",
      "skills": ["string"],
      "learning_outcomes": ["string"]
    }
  ],
  "concepts": [
    {
      "name": "string",
      "definition": "string",
      "examples": ["string"],
      "prerequisites": ["string"],
      "bloom_level": "string ('remember' | 'understand' | 'apply' | 'analyze' | 'evaluate' | 'create')",
      "difficulty": "string",
      "timestamp_or_page": "string"
    }
  ],
  "relationships": [
    {
      "from": "string",
      "to": "string",
      "relation": "string ('prerequisite' | 'part_of' | 'related_to')"
    }
  ],
  "important_sections": [
    {
      "title": "string",
      "timestamp_or_page": "string",
      "why_important": "string"
    }
  ],
  "created_at": "datetime (UTC)"
}
```
**Indexes**:
- `{ "resource_id": 1, "version": -1 }`

---

### 2.4 `skill_nodes` & `kg_edges` (Material Knowledge Graph)
- **`skill_nodes`**: Deduplicated repository of skill/concept entities.
```json
{
  "_id": "ObjectId",
  "name": "string (normalized, e.g. 'useeffect')",
  "display_name": "string (e.g. 'useEffect')",
  "description": "string",
  "type": "string ('concept' | 'skill')",
  "bloom_level": "string",
  "parent_id": "ObjectId | null",
  "prerequisite_ids": ["ObjectId"],
  "created_at": "datetime (UTC)"
}
```
- **`kg_edges`**: Connects concepts with directional relationships.
```json
{
  "_id": "ObjectId",
  "from_node_id": "ObjectId (ref: skill_nodes)",
  "to_node_id": "ObjectId (ref: skill_nodes)",
  "relation": "string ('prerequisite' | 'part_of' | 'related_to')",
  "material_id": "ObjectId (ref: analyses)",
  "created_at": "datetime (UTC)"
}
```
**Indexes**:
- `skill_nodes`: `{ "name": 1 }` (unique)
- `kg_edges`: `{ "material_id": 1 }`, `{ "from_node_id": 1, "to_node_id": 1 }`

---

### 2.5 `student_kg_state` (Student Knowledge Graph)
Authoritative competency state per student per concept.
```json
{
  "_id": "ObjectId",
  "user_id": "ObjectId (ref: users)",
  "node_id": "ObjectId (ref: skill_nodes)",
  "competency_score": "float (0.0 - 100.0)",
  "last_updated": "datetime (UTC)",
  "evidence_event_ids": ["ObjectId (ref: competency_events)"]
}
```
**Indexes**:
- `{ "user_id": 1, "node_id": 1 }` (unique compound index)

---

### 2.6 `assessments`, `attempts`, & `interview_sessions`
- **`assessments`**: Quiz structure generated for an exam session.
```json
{
  "_id": "ObjectId",
  "user_id": "ObjectId (ref: users)",
  "resource_id": "ObjectId (ref: resources)",
  "type": "string ('quiz' | 'interview')",
  "questions": [
    {
      "question_id": "string",
      "type": "string ('mcq' | 'short_answer' | 'code_explain')",
      "prompt": "string",
      "options": ["string"],
      "node_id": "ObjectId (ref: skill_nodes)",
      "target_bloom": "string"
    }
  ],
  "status": "string ('active' | 'completed')",
  "created_at": "datetime (UTC)"
}
```

- **`attempts`**: Submissions and evaluations for exam quizzes.
```json
{
  "_id": "ObjectId",
  "assessment_id": "ObjectId (ref: assessments)",
  "user_id": "ObjectId (ref: users)",
  "answers": [
    {
      "question_id": "string",
      "user_answer": "string"
    }
  ],
  "score": "float (0.0 - 100.0)",
  "per_question_result": [
    {
      "question_id": "string",
      "raw_score": "float (0.0 - 1.0)",
      "feedback": "string",
      "node_id": "ObjectId"
    }
  ],
  "created_at": "datetime (UTC)"
}
```

- **`interview_sessions`**: Multi-turn conversational interview records.
```json
{
  "_id": "ObjectId",
  "user_id": "ObjectId (ref: users)",
  "resource_id": "ObjectId (ref: resources)",
  "turns": [
    {
      "turn_index": "integer",
      "question": "string",
      "answer": "string",
      "evaluation": {
        "raw_score": "float (0.0 - 1.0)",
        "feedback": "string",
        "node_id": "ObjectId"
      },
      "ts": "datetime (UTC)"
    }
  ],
  "status": "string ('in_progress' | 'completed')",
  "created_at": "datetime (UTC)"
}
```

---

### 2.7 `competency_events`
Immutable evidence log produced by exam quizzes and interviews.
```json
{
  "_id": "ObjectId",
  "user_id": "ObjectId (ref: users)",
  "node_id": "ObjectId (ref: skill_nodes)",
  "source": "string ('quiz' | 'interview')",
  "raw_score": "float (0.0 - 1.0)",
  "weight": "float (default 1.0)",
  "ref_id": "ObjectId (ref: attempts | interview_sessions)",
  "created_at": "datetime (UTC)"
}
```
**Indexes**:
- `{ "user_id": 1, "node_id": 1, "created_at": -1 }`

---

### 2.8 `jobs`
Tracks background job status for asynchronous Strong Analysis processing.
```json
{
  "_id": "ObjectId",
  "type": "string ('strong_analysis')",
  "status": "string ('queued' | 'processing' | 'done' | 'failed')",
  "payload": "object",
  "result": "object | null",
  "error": "string | null",
  "created_at": "datetime (UTC)",
  "updated_at": "datetime (UTC)"
}
```
